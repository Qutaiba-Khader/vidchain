# Third-party notices

The app includes the components below, each under its own licence. Licence texts ship in the app's
open-source licences screen and in the `SOURCES-<tag>` bundle of every release.
The complete list - every library of the release runtime classpath, every native library inside the APK (the
youtubedl-android Python, ffmpeg and aria2c runtimes, lux and the Go modules linked into it) and every Python wheel
- is generated by `tools/licences.py` into `fallback-core/src/main/assets/vidchain-licences.json`, shown in the app
(Settings -> VidChain fallbacks -> Open-source licences) and checked in CI against the resolved dependencies.
The table below is a summary of the main components.

Note on GPL: the youtubedl-android library is GPL-3.0, and its ffmpeg build links GPL components (x264, x265, Xvid,
Rubber Band, vid.stab); aria2 is GPL-2.0-or-later and gallery-dl GPL-2.0. Their complete corresponding source is
available from their upstream projects (links in the licences screen), and VidChain's own complete source is attached
to every release (`SOURCES-<tag>.tar.zst`).
